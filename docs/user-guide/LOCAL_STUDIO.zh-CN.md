# 本地插帧工作室

这是正在开发的桌面版本，完整产品功能仍按 [开发任务清单](../DEVELOPMENT_PLAN.md) 推进。Studio 支持单个视频处理，任务队列支持批量文件和文件夹。本地界面不会上传视频或自动下载模型。

1. 按照 [桌面构建指南](../development/DESKTOP.md) 完成本地构建并启动程序。
2. 点击“选择文件”，或把一个视频拖进导入区域。程序会读取视频信息并检测 NVIDIA GPU。
3. 选择目标帧率。可以输入 `60`、`144` 或 `60000/1001` 等分数值。目标帧率决定生成的视频帧率，界面显示的“处理 FPS”表示本机实际处理速度。进度区会按源视频声明时长估算输出帧总数和剩余时间；这是估值，最终帧数以解码时间轴验证结果为准。工作期间还会显示 RIFE 推理、视频编码、解码和预处理/色彩转换的累计耗时，完成后补上输出验证时间，便于判断慢点位于哪一阶段。
4. 选择输出位置和编码器。默认生成带 `_RifeLove` 的新 MKV 文件；已有文件不会被覆盖。音轨或字幕与目标容器不兼容时，任务会明确报错，请选择适合的容器。
5. 在本地模型区域选择已校验的模型包，以及本机 TensorRT/ONNX Runtime CUDA 运行库目录。本地运行包默认选中 RIFE 4.25，并附带 RIFE 4.26 作为另一项可选模型；这不代表 4.26 画质更好。
6. 点击“开始补帧”。程序会先加载模型，处理完成后重新解码检查输出。通过检查后才发布最终视频。

当前模型路径支持模型清单声明的 BT.709 与 BT.470BG/SMPTE 170M 8/10-bit SDR，并按视频标记的矩阵处理和保留色彩信息。若 H.264 帧内的 BT.601 系列标签与容器标签只有已支持的矩阵别名或 SDR 传递函数差异，且像素格式、位深、原色和范围一致，程序会统一采用容器标签；其他冲突仍会报错。HDR、其他位深或色彩标记不明的视频仍不支持，界面会阻止已识别的不支持输入。10-bit 目前有合成色彩转换测试，真实素材画质尚未验收。请勿通过修改标签来假装完成真实色彩转换。

“自动 H.264”先检查 GPU 编码；若 NVENC 无法启动，会切换到软件 H.264 并继续补帧。当前电脑上的 FFmpeg 需要更新版本的 NVENC 驱动接口，所以会看到 `Function not implemented`。这是编码器回退提示，不代表插帧失败；新版界面会说明已改用软件编码，RIFE 推理仍在 NVIDIA GPU 上运行。“处理 FPS”是实际生成速度，不是最终输出帧率；例如 5.1 处理 FPS 表示每秒正在生成约 5 帧，帧数持续增长就代表任务仍在推进。若旧运行包显示原始 FFmpeg 错误，请从新版运行包启动；若进度不再增长且任务状态变为“失败”，再查看详情中的最终错误。

高级编码设置中可以显式选择“NVIDIA H.264（NVENC）”，并使用 VBR + CQ 恒定质量（0–51）。该模式只在当前源视频的 NVENC 编码器预检成功时可开始；本机驱动当前不满足要求，因此应继续使用“自动编码”或可用的软件编码器。CQ 越低通常文件越大；不同编码器的 QP/CRF/CQ 数值不能直接比较。

## 批量任务队列

1. 打开左侧“任务队列”，选择多个视频，或选择包含视频的文件夹。可以启用“扫描子文件夹”，也可以把文件或文件夹拖入队列。
2. 选择目标帧率、容器、编码器、本地模型包和 ONNX CUDA 运行库。输出文件夹可以留空，此时使用首个来源文件所在目录。
3. 点击“加入队列”。程序会检查文件和模型支持的色彩格式，跳过重复来源及已知输出，并为每个视频分配不会覆盖已有文件的新名称。当前本地模型清单接受明确标记的 BT.709 与 BT.470BG/SMPTE 170M 8/10-bit SDR；HDR、模型未声明的输入配置、未标记色彩和不可读取文件会显示为跳过原因。
4. 点击“开始队列”。任务依次处理；列表显示状态、模型阶段、处理帧数和实际处理速度。队列使用本机应用数据目录下的 SQLite 数据库，FPS、模型、运行库、输出位置、编码器和容器偏好保存在相邻的本地设置文件中。
5. “暂停”会等待安全检查点并保留当前运行中的任务；“继续”恢复同一工作任务。“停止队列”取消当前任务并保留之后排队的任务。失败任务可重试；异常中断任务可选择新输出名从头重启。

暂停不是断点续传。异常中断后，RifeLove 不会从记忆中的帧号继续拼接；真正的分段断点恢复仍在开发中。关闭处理窗口会提示取消正在进行的工作并等待资源清理。

## 对比预览

完成任务后打开左侧“对比预览”，原片和结果会在本机并排播放。可以切换原片/结果文件、拖动时间轴、同步播放或按输出帧率步进。当前步进按时间戳定位；精确到解码帧和自动跳转伪影位置仍在开发中。页面不会上传视频。
