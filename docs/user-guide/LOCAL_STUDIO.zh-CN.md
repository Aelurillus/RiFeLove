# 本地原生插帧工作室

状态核对：2026-10-31。本指南对应 `apps/native_desktop` 的 Windows 原生界面；旧 Qt 页面、旧预览包或单独构建的 EXE 不能作为当前完整产品的验收结果。完整范围仍按 [SRS](../SRS.md) 和 [开发任务清单](../DEVELOPMENT_PLAN.md) 推进。本机处理不上传视频，也不自动下载模型。

## 导入与导出

1. 按 [桌面构建指南](../development/DESKTOP.md) 启动本机构建，或使用已经核对依赖和校验清单的本地包。点击“导入视频”选择文件，也可使用“导入文件夹”批量发现素材。导入拒绝会显示具体原因；文件头声明的 FPS/时长不等于完整 VFR 扫描的结果。
2. 在“本地模型中心”核对本地模型和默认项。当前保留的插帧模型为 RIFE 4.25；历史测试过的其他版本不表示当前包中仍有这些权重。缺少模型时应选择有效的本地模型包，不能只填一个不存在的 ONNX 路径。参见 [本地模型中心](NATIVE_MODEL_CENTER.zh-CN.md)。
3. 选择目标帧率，或选择“自定义有理数”输入例如 `60000/1001`。输出 FPS 表示文件播放帧率；“处理 FPS”表示本机实际生成速度，两者不同。精度仍为 FP32；未通过验证的 FP16 不作为可用选项。
4. 选择“自动（NVENC 优先）”、“H.264 NVENC”或“软件 H.264”，并检查输出位置。自动策略检查实际编码器初始化后才决定硬件或软件路径；显式 NVENC 请求不保证每台机器可用。当前兼容的本地 FFmpeg SDK 在开发机上已有短片 H.264/HEVC NVENC 写出证据，不能继续把旧 SDK 的 `Function not implemented` 当作所有当前构建的固定状态。
5. 平台预设只生成本地副本，不登录或上传 YouTube、Bilibili、抖音，也不保证平台最终的编码、转码或播放帧率。单文件与批量使用同一个码率/GOP 策略；批量按每个实际解析的源文件及输出尺寸计算，竖屏按输出短边分档。精确的分数 FPS 保留。详情见 [平台导出策略](../architecture/PLATFORM_EXPORT.md)。
6. 点击“开始插帧”。原生任务通过本地队列执行，提供暂停、继续、取消和“任务历史”入口。源文件不会被修改；目标已存在、音轨/字幕与容器不兼容等情况会明确报告。完成文件须经过媒体与时间轴验证后才发布。暂停与进程退出后的检查点恢复不同，恢复条件及尚未覆盖的故障场景见 [队列说明](../development/QUEUE.md)。

当前输入仍受模型声明的 SDR 色彩范围约束。HDR、未知色彩或未受支持的转换应报告为不支持；不能靠改标签代替色彩转换。8/10-bit SDR 的小型合成验证不代表真实素材画质、HDR 或全部编码器已经验收。数据、日志与模型的位置见 [本地数据说明](NATIVE_DATA.zh-CN.md)。

## 小窗口操作

客户区小于 760 DIP 时，设置改为单列，侧栏收窄；底部开始、暂停和取消保持可见。设置区可滚动，提示文字说明滚轮与 Tab 的用法。滚轮位于输入框、按钮或未展开下拉框上时滚动设置，不改变下拉选项；下拉列表展开时由列表接收滚轮。Tab/Shift+Tab 会将可操作的设置滚入视区，禁用或折叠的项目会跳过。

已用真实 HWND 检查 480、600、700、790、800、850 DIP 外窗宽度，包括断点切换、滚动后输出路径/超分/曝光控件和键盘焦点。100–200% 缩放的布局计算也有覆盖。隔离桌面的 Direct2D 渲染已经人工查看；真实多显示器 DPI 切换、完整辅助功能和物理屏幕视觉验收仍待完成。

启用兼容的 x2 超分模型后，1440p/2160p 目标保留源宽高比，不强行拉伸为 16:9。尺寸采用模型能力内、编码器上限内的偶数像素组合；不能精确到档位时显示“约”，例如 2560×1080 可得到 3456×1458（约 1440p），而不是谎称精确 1440 行。超出 x2 能力的选项会拒绝；未载入有效尺寸时提示导入后计算。

## 可选降噪与曝光

首次默认不启用“可选降噪”；已保存的模型默认项按模型中心设置恢复。选择 FastDVDnet 后，即使“自动降噪：关”，仍会执行固定 σ25 的时序降噪；这里的“关”仅指自动估计关闭。完全关闭降噪，应将“可选降噪”切回关闭。

点击自动降噪按钮会先显示“实验性自动高斯降噪”说明。选择“是”才启用自动模式，“否”回到固定模式，“取消”保留当前状态。必须先选择已校验的 FastDVDnet。自动模式默认关闭；移除模型会清除开关，重新选择模型不会偷偷启用。

自动模式只估计近似加性高斯噪声并调整模型条件；实际合成测试已出现把有意保留的胶片颗粒当作噪声去除的情况，可能损失细节。它不是压缩修复、通用细节恢复或去模糊。当前自动模式强制软件源解码，神经推理仍使用选定的 GPU 后端；恢复任务需从头重放源片前缀，不能当作快速跳转续跑。设置及模型身份会进入持久化任务，改变模式应新建任务。详见 [自动高斯降噪的证据与限制](../architecture/AUTOMATIC_GAUSSIAN_DENOISE.md)。

“自然动态曝光”是独立选项，通过快门角度和采样数控制时间积分；它不证明去压缩、细节恢复或真实视频质量已经完成。高帧率母版和平台副本可分别设置。小型合成流程测试与真实长视频、画质/性能验收须分别看待。

## 静态逐帧比较

点击主窗口“逐帧比较”，在原生窗口中选择原片和已完成的结果。窗口按两条视频各自的时间轴原点，在同一相对时间显示最近的已解码帧。可拖动位置、输入秒数或有理数时间跳转，并使用上一帧/下一帧切换实际输出 PTS。窗口可调整大小、关闭及重新打开；旧请求不会覆盖新的位置结果。

当前是并排静态帧查看，**没有视频播放、音频或同步播放**，也没有自动伪影定位。显示保持编码像素的比例；界面明确提示“SAR 尚未校准”，不能用于非方形像素素材的正确显示比例验收。存在旋转或非恒等显示矩阵（包括只有镜像、位移）的文件会明确拒绝，而不是以错误方向展示。缺少流起点时先解码首帧取得可靠 PTS；无法取得可靠原点会报告错误，不假设从 0 开始。HDR、未知色彩及不支持的预览转换仍受限制。

真实解码测试覆盖小型本地 SDR 原片/结果的同时间定位、实际相邻帧、滑块、结尾及零旋转镜像/位移拒绝；窗口状态测试覆盖取消、请求合并和关闭重开。此前一帧定位在缺少前邻时间戳时可能从开头扫描，虽可取消，长视频延迟尚未验收。SAR、完整 VFR/色彩矩阵、真实素材视觉质量、同步播放及多小时稳定性仍在完整产品验收范围内。
