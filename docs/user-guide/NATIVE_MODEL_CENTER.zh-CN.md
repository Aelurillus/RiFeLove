# Native 本地模型中心（首阶段）

Native Win32 完整媒体构建的左侧「本地模型中心」打开独立窗口。模型中心不访问运行时网络服务，也不会因为来源清单中包含网址而打开它。当前版本可安装用户已下载到本机的模型 ZIP 和旁边同名的 `.distribution.json` 清单，尚未提供在线目录或下载渠道。

1. 查看程序 `models` 目录下的模型包，或点击「登记本地目录…」选择包含 `model.json` 的本机目录。登记只记录原目录，不复制权重。
2. 安装 ZIP 包时，先从同一下载位置取得 ZIP 与对应的 `.distribution.json` 清单，放在同一文件夹，并保持归档文件名与清单声明一致。点击「安装验证包…」选择 ZIP。模型中心在后台验证归档 SHA-256、清单列出的每个文件和 RIFE schema-v2 元数据，只解压允许的文件；进度显示在窗口中，可以随时取消。
3. 通过验证的模型会原子移入 `%LOCALAPPDATA%\RifeLove\Models` 下的版本目录，再登记到模型中心。取消或失败会清理暂存文件，不会覆盖现有模型。所选清单中的哈希证明文件内容一致，不认证发布者身份；请只使用可信下载来源。
4. 在列表选择模型，条目会显示 SHA-256 前 8 位，便于区分同名版本；详情显示完整 SHA-256、许可、来源仓库与提交、数值验证配置、验证后端、能力、适配器、颜色/输入配置和可复制的完整路径。
5. 点击「设为该类默认」，分别保存 RIFE 插帧、超分和时域修复的默认项。默认 RIFE 用于主窗口；超分和降噪默认项同步至主窗口的实际作业选择器。仍可在主窗口临时关闭可选超分或降噪；下次启动/重新校验恢复已保存的默认项。
6. 「取消登记」移除应用登记并清除对应默认项，不删除外部原目录或托管模型文件。已取消登记的随包模型不会在下次扫描时自动恢复；可再次明确登记同一目录。

默认设置保存在 `%LOCALAPPDATA%\RifeLove\local-models.txt`，队列位于同一目录的 `queue.sqlite`，安装在 Program Files 时也使用该用户目录。显式便携模式和旧数据迁移行为见[本地数据目录](NATIVE_DATA.zh-CN.md)。设置采用 UTF-8 路径和原子替换，写入失败时更改不生效；文件损坏、无法读取或旧设置迁移失败时，模型中心保留只读查看能力并阻止覆盖原设置。详情中显示实际数据目录、旧目录和迁移提示。

首次没有用户默认项时，继续识别 `models/default-model.txt` 中的 UTF-8 BOM/CRLF 路径；用户默认项优先。已保存的 RIFE 默认项失效时会阻止就绪，不会暗中改用另一个 RIFE 包。

每次启动、登记和「重新校验」都复用现有校验器检查权重、许可、来源清单及验证报告的哈希与契约。详情中的 SHA-256 与许可/来源字段来自模型包声明；完整性通过只说明本地文件与清单一致，**不认证作者、许可再分发权或画质**，也不等于真实模型推理/显卡验证。来源和验证报告属于声明式元数据，不会执行模型目录中的代码。

当前原生处理可选择已支持的 `rife-sdr-v1` 插帧、×2 输出端超分以及 FastDVDnet 源帧率时域降噪。其他校验通过的包可查看和登记，但「设为默认」明确禁用；×4 超分、单帧去模糊、未知适配器不会伪装为当前原生流程的可用能力。旧格式 RIFE 包缺少完整侧车元数据时会显示校验边界，不能通过模型中心设为默认。

选择 FastDVDnet 后，默认使用固定 σ25 时序降噪；主窗口的“自动降噪：关”仅表示自动估计关闭，不表示已绕过所选模型。要完全关闭降噪，请在“可选降噪”选择关闭。实验性自动高斯模式必须另行明确启用，默认关闭；它会强制软件源解码、恢复时从头重放，并可能误去除有意保留的颗粒。取消降噪模型选择会清除自动开关，重新选择模型不会自动开启。说明与未验收范围见 [本地工作室指南](LOCAL_STUDIO.zh-CN.md) 和 [自动高斯降噪](../architecture/AUTOMATIC_GAUSSIAN_DENOISE.md)。

模型路径限定为本地盘绝对目录；UNC/映射网络盘和重解析点会被拒绝。ZIP 安装使用后台进度和取消；启动/重新校验仍对当前目录同步执行。模型目录复制只发生在明确的安装操作中。当前版本没有在线下载、断点续传、来源签名认证、缓存清理和物理删除功能。视频检查或任务运行期间暂停登记和默认项更改，避免改变正在使用的选择器。窗口使用原生控件和独立 DPI 字体，窄窗口将列表与详情上下排列。

开发回归覆盖独立临时模型包，不读取或改动真实模型包：设置往返、中文路径、三类登记和默认项、跨实例恢复、损坏侧车拒绝、未知能力禁用、取消登记不删除、重新登记和窄窗口几何。真实多屏 DPI、长路径目录选择及大模型等待体验仍需人工验收；离屏控件测试不作为真实窗口视觉证据。
