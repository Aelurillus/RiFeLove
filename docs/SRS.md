# RifeLove software requirements specification

Version 0.1 implementation baseline. The authoritative product scope is [the original Master Plan V1.0](MASTER_PLAN_V1.0.zh-CN.md), extended by the user's later restoration requirement, non-Qt desktop decision and desktop-only delivery: no end-user CLI is required or included in the product package. All applicable P0, P1 and P2 desktop items remain required. Source videos, settings, task databases/history, logs and checkpoints remain local, and the application processes models locally. Alibaba Cloud OSS is disabled. The user previously authorized Storj for major-release backups; it is currently disabled because no bucket is configured. Backups may contain only reviewed release artifacts, never user media or task data.

Several implementation records below describe the previous Qt desktop or core-level tests. They do not establish that the corresponding workflow has been migrated to the native desktop. Native UI parity and its own evidence remain open until explicitly verified.

## Final completion gate

In addition to R28, the user requires motion-aware temporal restoration for compression artifacts, lost detail and noise, alongside optional natural motion blur. The three restoration controls also need independent content-adaptive estimates and user adjustments relative to automatic settings, reflecting the interaction described in [Topaz's public documentation](https://docs.topazlabs.com/topaz-video/filters/enhancement). This is a behavioral reference, not a claim of using or reproducing proprietary models. A qualified implementation must demonstrate temporal stability and cut/edge behavior on video, preserve the media timeline, and document model provenance, licensing, quality and GTX 1660 SUPER performance. Existing single-frame x2 super-resolution and deblur evidence does not establish that capability.

All seven Master Plan delivery groups remain unaccepted: complete desktop application, real RIFE GPU interpolation, complete media/color, queue/recovery/models, preview/quality/quality restoration/encoding, tests/benchmarks/docs, and installable compliant continuously maintainable distribution. Passing the current foundation suite proves only the behaviors explicitly covered above. The goal remains active until every required capability and release gate has direct evidence.
