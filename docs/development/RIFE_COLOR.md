# Initial RIFE SDR color contract

`prepareRifeSdr` and `restoreRifeSdr` form a CPU preprocessing/postprocessing boundary independent of the inference backend. This is a tested subset of the complete color pipeline, not HDR or complete SDR format acceptance.

The input must have owned, valid pixel planes with positive dimensions <=8192, 8-bit components, explicit BT.709 or BT.470BG/SMPTE 170M primaries, and an explicit BT.709 or sRGB transfer. RGB requires `gbr` matrix/full range. YUV accepts BT.709 matrix with BT.709 primaries, or BT.601-family `smpte170m`/`bt470bg` matrix with matching legacy primaries; range must be explicitly full or limited. Hardware surfaces, alpha, palette, unknown metadata, higher depth and HDR are rejected. Primaries and transfer are preserved: these are normalized **nonlinear RGB** values in the source gamut, not linear-light/tone-mapped values.

libswscale is configured with explicit BT.709 or BT.601-family coefficients and source/destination ranges based on the tags. An RGB48 intermediate avoids an extra RGB8 quantization before FP32 normalization. The contiguous batch-1 NCHW buffer is padded to a multiple of 64 by repeating the last row/column. The configured float-buffer limit is checked before allocation; this limit does not cover all temporary buffers or GPU inference memory. Cancellation is checked around conversion and between rows.

Postprocessing validates finite normalized pixels, crops to the original dimensions and converts through RGB48 back to the original 8-bit layout/range/matrix. The returned frame owns its planes independently. Presentation timestamps/durations remain the timeline's responsibility. This path does not add HDR qualification to a model or silently infer missing color information.

Five unit cases check RGB channel order/edge padding/crop/ownership, limited-range black/white and tags, known BT.709 and BT.601 limited-range red code values, source-tag preservation and rejection of unknown color/HDR/depth/nonfinite pixels/budget/cancellation. A full desktop workflow runs a tagged BT.470BG/SMPTE 170M source through CUDA RIFE and verifies output color tags and audio. These are numeric conversion tests; gamut/clipping policies, full chroma-position coverage, HDR/10-bit, visual quality and GPU conversion remain required.
